BUSINESS — Android-проект (версия 1.0)
=====================================

Что есть:
- Главная: текущий баланс, цель капитала, доходы, расходы и прибыль.
- Товары: закупочная цена, количество, доставка, цена продажи, остатки.
- Продажи: запись количества и фактической цены продажи.
- Операции: доход, расход, начальный/добавленный капитал, изъятие.
- Статистика: итоги, сравнение доходов/расходов и категории затрат.
- Резервное копирование JSON и экспорт операций CSV.
- Офлайн-хранение на устройстве.

ВАЖНО:
1. Это исходный проект, а не готовый подписанный APK.
2. Для сборки нужен Android Studio и Android SDK (API 35), Java 17+.
3. Открой папку Business в Android Studio, дождись Gradle Sync.
4. Выбери Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.
6. Перед использованием реальных денег протестируй расчёты на небольших тестовых суммах.
7. Данные локальные. Делай экспорт JSON регулярно; удаление приложения/очистка данных может удалить записи.

Расчёт:
- Баланс = стартовый капитал + доходы + пополнения − расходы − изъятия.
- Покупка товара и доставка учитываются как расход.
- Прибыль товара рассчитывается по фактической цене продажи минус себестоимость и распределённая доставка.
- Прибыль от продаж уже отражается в разнице между доходом от продажи и ранее записанными расходами на закупку; показатель прибыли товара предназначен для анализа товара и не прибавляется к балансу второй раз.

ПРИМЕЧАНИЕ ДЛЯ РАЗРАБОТЧИКА:
Для корректного начального баланса внеси стартовую сумму через Операции > Начальный капитал / пополнение.


СБОРКА БЕЗ КОМПЬЮТЕРА (через GitHub Actions):
1. Создай аккаунт/войдите на github.com в браузере телефона.
2. Создай новый репозиторий с именем Business и загрузи в него файлы этого проекта (содержимое ZIP, а не сам ZIP).
3. Убедись, что файл .github/workflows/android.yml присутствует в репозитории.
4. Открой вкладку Actions, выбери "Build Business APK", нажми Run workflow.
5. После успешного завершения открой запуск workflow и скачай артефакт Business-debug-apk.
6. Распакуй скачанный ZIP с артефактом; внутри будет app-debug.apk.
7. Нажми на APK и разреши установку из этого источника, если Android попросит.
Проверяй, что скачиваешь артефакт из собственного репозитория. Debug APK не предназначен для публикации в Play Store.
